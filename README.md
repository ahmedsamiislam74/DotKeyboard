# Dot Keyboard (Pixel 6)

## Build the APK
1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open > choose this DotKeyboard folder. Let Gradle sync (accept any SDK/Gradle download prompts).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK appears in app/build/outputs/apk/debug/app-debug.apk. Copy it to your Pixel 6 and tap it to install
   (allow "install unknown apps" for your file manager/browser).
   Or: enable USB debugging on the phone, plug in, and press the green Run button.

## Turn it on
Open the "Dot Keyboard" app > "1. Enable keyboard" > toggle Dot Keyboard on > back > "2. Switch keyboard" > pick it.

## Using it
- Tap = letter. Hold a key = the small symbol in its corner (q = 1, a = @ ...).
- Shift: tap once = one capital, double-tap = caps lock.
- Hold backspace to keep deleting. ?123 = numbers/symbols, ABC = back.
- The smiley key jumps to your next keyboard (e.g. Gboard) for emoji.
